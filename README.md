# EngiDock Course Notes

Condensed notes and exercises that accompany specific courses on [engidock.com](https://www.engidock.com).

These are **not** replacements for the courses — they're the kind of notes you'd take while going through one, published so anyone can use them as a refresher or a study guide.

## Contents

- [`kubernetes/`](./kubernetes) — notes for the Kubernetes course

## Contributing

If you've taken an EngiDock course and want to contribute your own notes for a course that isn't covered yet, open a pull request with a new folder named after the course.
