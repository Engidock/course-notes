# CSS — Hands-On Project Lab

> Build a responsive landing page with Flexbox and Grid.

## Objective

Practice modern layout techniques and a real mobile breakpoint, not just tutorial boxes.

## Prerequisites

- A code editor and a browser

## Steps

1. Build a hero section with a Flexbox nav bar (logo left, links right).
2. Build a 3-column features section using CSS Grid.
3. Add a mobile breakpoint (e.g. below 768px) that stacks the grid into a single column.
4. Use CSS custom properties (variables) for your color palette and spacing scale.
5. Add a hover/focus state to every interactive element for accessibility.
6. Run the page through a Lighthouse accessibility audit and fix at least 2 flagged issues.

## Deliverable

A responsive page verified at 3 breakpoints, plus a before/after Lighthouse accessibility score.

## Stretch goals

- Add a CSS-only dark mode toggle using `prefers-color-scheme` and custom properties.
