# Django — Hands-On Project Lab

> Build a CRUD app with models, views, templates, and authentication.

## Objective

Ship a working, authenticated web app using Django's batteries-included approach.

## Prerequisites

- Python 3
- Basic web concepts

## Steps

1. Scaffold a Django project and one app (e.g. `tasks`).
2. Define a model (e.g. `Task`) and run migrations.
3. Build list/create/update/delete views using Django's class-based views.
4. Wire up templates extending a shared base template.
5. Add Django's built-in auth so tasks are scoped to the logged-in user.
6. Write at least 3 tests covering the create and delete views.

## Deliverable

A running app where a logged-in user can only see and manage their own tasks, with passing tests.

## Stretch goals

- Add Django REST Framework and expose the same model as a JSON API.
