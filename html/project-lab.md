# HTML — Hands-On Project Lab

> Build a semantic, accessible multi-section page from scratch.

## Objective

Practice writing HTML that means something to screen readers, not just to the eye.

## Prerequisites

- A code editor and a browser

## Steps

1. Structure the page with `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, and `<footer>` — no generic `<div>` soup.
2. Add a skip-to-content link as the first focusable element.
3. Use proper heading hierarchy (one `<h1>`, logically nested `<h2>`/`<h3>`).
4. Add `alt` text to every image and `aria-label`s where visual context is missing.
5. Build a form with properly associated `<label>`s and fieldset grouping.
6. Validate the page against the W3C HTML validator and fix every error.

## Deliverable

A W3C-valid page that a screen reader can navigate section-by-section using landmarks.

## Stretch goals

- Test the page with an actual screen reader (VoiceOver/NVDA) and fix anything confusing.
