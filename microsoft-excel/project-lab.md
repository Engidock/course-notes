# Microsoft Excel — Hands-On Project Lab

> Build a sales dashboard using pivot tables and lookup formulas.

## Objective

Turn a raw, messy sales export into a decision-ready one-page dashboard.

## Prerequisites

- Excel (or Google Sheets)
- A sample sales dataset

## Steps

1. Clean the raw data: remove duplicates, fix inconsistent date/text formats.
2. Build a pivot table summarizing revenue by region and month.
3. Use XLOOKUP (or VLOOKUP) to pull a product category onto each row from a separate lookup table.
4. Add conditional formatting that highlights months where revenue dropped more than 10% vs the prior month.
5. Build a chart (line or bar) driven directly by the pivot table.
6. Add a slicer so the dashboard can be filtered by region without editing formulas.

## Deliverable

A one-page dashboard tab that updates correctly when you change the region slicer.

## Stretch goals

- Replace the static pivot with a dynamic array formula (FILTER/SORT) version of the same summary.
